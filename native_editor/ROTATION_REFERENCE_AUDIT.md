# UE2 rotation reference audit (research)

The provisional DX2Ed GLB exporter currently computes `Rz(Yaw) * Ry(-Pitch) * Rx(Roll)`.
An independent comparison with the T3SDK/UE2 `FRotationMatrix` convention
indicates that `Rx(-Roll)` yields the UE2 reference basis, for arbitrary
Pitch/Yaw/Roll, after the same Unreal-to-GLB axis swap.

This is **reference mathematical parity**, not a measured retail Invisible War
renderer transform. It does not solve source mesh pivots, nonuniform scale,
BSP positioning, or the Trier 180-degree pipe: `-180° == +180°`.

## Automatic native editor integration

On every successful native GMP import, DX2Ed writes a read-only
`rotation_audit.json` next to the existing `actors.json` and
`scene.report.json` in its private content-hashed cache. Both Auto Roll ON
and OFF create their own cache and their own audit file; the audit uses the
unaltered **source actor rotations** in either mode.

When an older cached scene has no rotation audit, opening it backfills the
companion report **without rebuilding the GLB or invalidating saved drafts**.
No original GMP/IBD files are ever modified. For older standalone Actor
Explorer exports, use the CLI below on an `actors.json` file instead.

Run on a private `actors.json` generated by DX2Ed:

```powershell
python native_editor/godot_editor/backend/dx2_rotation_audit.py "C:\\your-cache\\actors.json" --output "C:\\your-cache\\rotation-audit.json"
python -m unittest discover -s native_editor/tests -p "test_rotation_reference_audit.py" -v
```

The report is a separate JSON file, with map/source hash, per-actor export ID,
mesh name, unmodified rotator, and maximum absolute matrix error relative to
the UE2 reference. Only mesh-linked actors are included. Invalid rotators are
counted and surfaced without guessing repairs.

The tool never patches game archives, GLB scenes, actor drafts, or source
metadata. Existing 0.5.5 Auto Roll behavior is deliberately unchanged.
