# Research provenance and publishing boundaries

Early DX2Ed research builds include local resource parsers, map/glTF exporters, a TriggerScript parameter editor, skeletal UV analysis, and a read-only Thief 3 editor compatibility audit.

The assembled source-only starter is named `DX2Ed_GitHub_Starter_Source_0.1.zip` (54 files). Additional files from that research archive should be added only after review. This initial repository contains documentation and a source checker; it **is not yet** the full research archive.

The project has used user-supplied Deus Ex: Invisible War installations and the official Thief: Deadly Shadows editor archive for compatibility study. **No retail assets or original game/editor binaries are meant to be distributed here.**

Audit any third-party code reuse and satisfy its licenses before publication. No repository-wide code license has been selected.
