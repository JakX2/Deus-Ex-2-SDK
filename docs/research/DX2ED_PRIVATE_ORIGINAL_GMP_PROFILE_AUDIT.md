# DX2Ed original GMP capsule profiles: private replay and redacted aggregate audit

**Experimental owner-local research only**, stacked on PRs #50–#54. This is an audit of reproducible **fixed-axis static source-triangle capsule contact calculations**, **not** an independent game Havok runtime test, a player-controller walkability solver, or a proof of traversal.

**No original retail GMP files, owner-generated profile JSON, manifest, original triangle IDs, original map names, SHA-256 values, path coordinates or first-contact timing are to be committed to GitHub.** The audit emits only coarse counts after successfully recomputing **every** private profile against its original GMP. The aggregate output is deliberately small, but **aggregation is not cryptographic anonymization** and can still be sensitive.

## What the tool verifies

Run `research/dx2/audit_private_capsule_height_profiles.py` on the computer holding your own licensed/original GMP files and your already-generated **private** PR #52 multi-height profile JSONs.

For each input profile:

1. Read a bounded private manifest and a bounded existing `DX2Ed-source-edge-capsule-height-profile-v1` JSON, requiring source map filename/SHA, original Level +Z axis, read-only flags, ordered sample elevations, preview-space baseline positions, radius and capsule axis half-length.
2. Invert the *documented* preview transform `(Level.x/10, Level.z/10, Level.y/10)` back to original Level XYZ, with fixed axis `(0,0,1)`.
3. Call the **existing** read-only GMP exporter. It rehashes and reopens the owner-original `.gmp`, independently audits Level triangles/MOPP provenance, and recomputes **every** elevation using complete source-triangle capsule first-contact, the separate complete-sweep oracle and conservative MOPP candidate inclusion.
4. Write the recomputed **private derived profile** into a uniquely named temporary directory beside the requested report; this temporary directory is automatically removed after success **or failure**.
5. Compare **all** fields of the original profile against the recomputed document, including map identity, flags, path and shape, height offsets, triangle identities, contact counts, first-contact path times and overlap/tangency flags. Fixed values and IDs compare exactly; numerical floating values allow a tiny `1e-6` absolute / `1e-8` relative cross-platform tolerance.
6. **Fail closed:** Any missing/modified map, malformed sidecar, missed source contact, mismatched hash, duplicate input, wrong source triangle or changed result refuses the **entire** report, leaving no final output.
7. Publish a fresh, **aggregate-only** JSON outside the checkout and original `Maps` directory, containing no owner-derived coordinates, no per-map breakdowns, no original map names, no hashes and no original triangle IDs. Counts include verified GMPs, profiles, height samples with/without geometric contacts, cases touching any source triangle and coarse per-sample contact-count buckets (0, 1, 2–4, 5+).

**Boundary:** A recomputed result validates that a supplied private chord and shape produce those static geometry contacts. The audit does not itself prove that the baseline chord was selected from an exact shared source edge. Prefer profiles generated by DX2Ed's authenticated **Profile capsule heights** UI, which performs that separate upstream chord check. Nor can a successful source-GMP audit prove actual Havok or player behavior.

## Keep the inputs private

Create **all** owner data and the report directory **outside this GitHub checkout**. Example local directory layout on Windows:

```text
D:/DX2Private/
    Maps/               # your unmodified owner-original .gmp files
    Profiles/           # DX2Ed's private capsule_live_*.json files
    manifest.json       # owner-local, NEVER commit
    Reports/            # safe location for new redacted_aggregate.json
```

Manifest example using **illustrative local paths only**:

```json
{
  "schema": "DX2Ed-private-GMP-capsule-profile-audit-manifest-v1",
  "cases": [
    {"map_file": "Maps/Example_A.gmp", "private_profile": "Profiles/edge_A.json"},
    {"map_file": "Maps/Example_B.gmp", "private_profile": "Profiles/edge_B.json"},
    {"map_file": "Maps/Example_C.gmp", "private_profile": "Profiles/edge_C.json"}
  ]
}
```

All relative paths are resolved relative to the manifest file; absolute paths are also allowed. The real `Example_*.gmp` names above are placeholders, not provided data. Input profiles must be private files outside `Maps` and outside the SDK checkout. The report must be a **new** `.json` with an existing parent folder outside both.

In Windows PowerShell, from the checked-out repo:

```powershell
py -3 research/dx2/audit_private_capsule_height_profiles.py --manifest "D:/DX2Private/manifest.json" --output "D:/DX2Private/Reports/redacted_aggregate.json"
```

The default requires **at least three distinct original GMP hashes** to avoid releasing tiny cohorts by accident. For a deliberately **local/private, single-map** verification, you may opt in to the risk with `--allow-small-cohort`. Never publish small-cohort aggregates blindly.

When successful, standard output contains only `status`, verified map/profile **counts** and `redacted_aggregate_only: true`. Failure prints a **fixed reason code**, not a private path, hash or geometry. The public report contains fixed schema labels and counts only; the private manifest and profiles are **never copied into it**.

## Report fields and interpretation

```json
{
  "schema": "DX2Ed-redacted-GMP-capsule-profile-audit-v1",
  "report_kind": "redacted_aggregate_only",
  "verified_original_gmp_count": 3,
  "verified_private_profile_count": 3,
  "total_capsule_height_samples": 9,
  "height_samples_with_source_triangle_contact": 3,
  "height_samples_without_source_triangle_contact": 6,
  "profiles_with_any_source_triangle_contact": 3,
  "contact_triangle_count_buckets": {
    "none": 6, "one": 3, "two_to_four": 0, "five_or_more": 0
  },
  "read_only": true,
  "original_game_assets_modified": false,
  "havok_runtime_contact_verified": false,
  "not_a_gameplay_walkability_classifier": true,
  "aggregate_counts_can_still_be_sensitive": true
}
```

The numbers above describe **invented synthetic fixture data**, not DX2's actual maps. A triangle contact may simply indicate floor support, and a no-contact sample is not a playable clearance verdict. This report describes tested input paths, **not** map-wide coverage or a statistically representative random selection. There are no percentages, per-map results or estimated player capsule dimensions in the report.

## Safety and verification

- Failures leave the final report absent. Existing files cannot be overwritten.
- The tool refuses to place manifests/profiles/source files within the SDK checkout, to put private profiles under source `Maps`, or to write reports under `Maps` / the checkout.
- Hard limits: 32 profile cases, 128 KB input manifest, 512 KB per private profile. The original GMP decoder already caps source input at 500 MB; each map is read-only.
- Original source paths and worker exception messages are suppressed rather than printed to CI/console. Do **not** redirect verbose logs from other tools or include your private manifest in bug reports.
- The new `native_editor/tests/test_dx2_private_original_gmp_profile_audit.py` covers three independent *synthetic mocked-source* report replays; tampered source SHA, first-hit and count mismatches; malformed/duplicate/oversized/private-input refusals; staging cleanup, small cohort defaults, output safety and non-leaking public report. It also confirms real exporter rejection of invented non-GMP bytes.
- **Still pending:** real owner GMP corpus replay, local Windows usability/performance test, measured cross-platform float drift, and gameplay Havok/controller parity.

Keep the work a draft PR until original-map verification is performed privately.
